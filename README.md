## Frontend

The parent portal frontend is organized under `frontend/parent-portal/`:

- `index.html` - portal page structure and content
- `css/styles.css` - portal styling and responsive layout
- `js/app.js` - navigation, animations, OTP demo login, and support-ticket interactions

Open `frontend/parent-portal/index.html` to run the portal locally. The root `islingtion-parent-portal.html` file redirects to this entry point for compatibility.
